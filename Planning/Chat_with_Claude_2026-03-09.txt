This is a great foundation. The two-state design is clean and the size/danger scaling gives you natural difficulty progression without overcomplicating it. Let me react to the design and suggest a few refinements.

## One Adjustment: Flip The Size/Aggression Relationship

Your instinct was small = more likely to attack cities, large = stays put. I'd actually flip this, or at least nuance it:

**Small kaiju** — skittish, guards small clusters, retreats if outnumbered, rarely invades unless provoked repeatedly. Think territorial animal, not apex predator.

**Medium kaiju** — confident, guards medium clusters, will chase vehicles further, occasionally invades if lured or angered.

**Large kaiju** — apex predator, guards the best resources and mountains, slow but devastating, rarely invades BUT when it does it's a catastrophic event that requires coalition response.

The reason is gameplay balance. If small kaiju attack cities frequently they become an annoying early-game tax rather than an interesting encounter. Large kaiju attacking cities should be rare and terrifying — a session-defining moment. That asymmetry makes each size feel distinct.

## State Machine

```cpp
enum class EKaijuState
{
    Idle,        // Wandering patrol area, calm
    Alerted,     // Detected something, moving to investigate
    Attacking,   // Actively fighting vehicles
    Pursuing,    // Chasing vehicles beyond normal radius
    Invading,    // Targeting a city directly
    Returning,   // Heading back to guard area after chase
};
```

The `Alerted` state is important — it's the window where the player can retreat and de-escalate before the kaiju commits to attacking. Without it the transition from peaceful to combat feels instant and unfair.

## Detection Radius Design

Your instinct about resource capturing triggering a larger awareness radius is excellent. Model it as a base radius plus provocation modifiers:

```cpp
float GetDetectionRadius(AVehicleActor* Vehicle)
{
    float BaseRadius = GuardRadius * 0.6f; // Passive awareness

    // Actively capturing nearby resource → kaiju "feels" it
    if (Vehicle->bIsCapturingResource && IsResourceInGuardArea(Vehicle->TargetResource))
        BaseRadius *= 2.5f;

    // Vehicle is damaged/in combat → kaiju drawn to disturbance
    if (Vehicle->IsInCombat())
        BaseRadius *= 1.3f;

    // Large groups trigger awareness at greater distance
    int32 NearbyVehicles = CountVehiclesNear(Vehicle->GetActorLocation(), 500.0f);
    BaseRadius += NearbyVehicles * 50.0f;

    return BaseRadius;
}
```

This means a single scout can slip past a kaiju undetected, but a mining fleet exploiting a resource cluster will absolutely draw aggression. That's great gameplay — it rewards careful scouting and punishes greedy resource grabs.

## Leash System

The leash prevents kaiju from wandering indefinitely while still allowing meaningful pursuit:

```cpp
struct FKaijuGuardData
{
    FVector GuardCenter;      // Center of patrol area
    float GuardRadius;        // Normal patrol bounds
    float LeashRadius;        // Maximum chase distance
    float InvasionRadius;     // Distance at which city becomes a target

    // Leash behavior
    bool IsWithinLeash() 
    { 
        return FVector::Dist(GetActorLocation(), GuardCenter) < LeashRadius; 
    }
    
    bool ShouldReturn() 
    { 
        return !IsWithinLeash() && CurrentState != EKaijuState::Invading; 
    }
};

// Size-based values:
// Small:  GuardRadius=800,  LeashRadius=1500, InvasionRadius=2000
// Medium: GuardRadius=1500, LeashRadius=2500, InvasionRadius=3500
// Large:  GuardRadius=2500, LeashRadius=3500, InvasionRadius=6000
```

The leash creates natural chokepoint gameplay — players learn they can kite a kaiju to the edge of its leash, then safely capture resources while it returns home.

## Invasion Triggers

Rather than purely random invasion, give each trigger a weighted probability that accumulates:

```cpp
float CalculateInvasionUrge()
{
    float Urge = 0.0f;

    // Passive accumulation over time (rare spontaneous invasion)
    Urge += TimeSinceLastInvasionCheck * BaseInvasionRate;

    // Provocation memory - each time vehicles escaped after raiding
    Urge += ProvocationCount * 15.0f;

    // City visible from current position
    if (IsCityVisibleFromCurrentLocation())
        Urge += 30.0f;

    // Currently pursuing vehicles heading toward a city
    if (bIsPursuing && IsTargetHeadingTowardCity())
        Urge += 50.0f;

    // Size modifier - large kaiju resist invasion urge
    Urge *= InvasionUrgeMultiplier; // Small=1.5, Medium=1.0, Large=0.3

    return Urge; // Invade when > 100
}
```

The provocation memory is key — players who repeatedly raid a kaiju's cluster and escape will eventually trigger an invasion. It feels like consequence rather than randomness.
