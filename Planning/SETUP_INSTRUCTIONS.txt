===========================================
SETUP INSTRUCTIONS FOR PLANET CONQUEST
===========================================

STEP 1: COMPILE THE CODE
===========================================

The C++ files have been created. You need to compile them:

OPTION A - Close Editor and Compile:
1. Close Unreal Editor completely
2. Open PowerShell in the project directory
3. Run this command:

& "C:\Program Files\Epic Games\UE_5.5\Engine\Build\BatchFiles\Build.bat" Planet_ConquestEditor Win64 Development "c:\Users\benja\Documents\Unreal Projects\Planet_Conquest\Planet_Conquest.uproject" -waitmutex

OPTION B - Compile from Editor (EASIER):
1. In Unreal Editor menu bar: Tools > New C++ Class > Cancel (this opens the project in your IDE)
2. Or just click "Compile" button in the toolbar
3. Or press Ctrl+Alt+F11 to recompile while editor is open


STEP 2: SETUP ENHANCED INPUT (NEW UE5 SYSTEM)
===========================================

After compiling, you need to create Enhanced Input assets:

1. CLOSE UNREAL EDITOR COMPLETELY
2. Reopen the project (to load the newly compiled classes)

3. CREATE INPUT ACTION ASSETS:
   - Content Browser > Right-click > Input > Input Action
   - Create these 3 Input Actions:
   
   a) Name: IA_Move
      - Value Type: Axis2D (Vector 2D)
      
   b) Name: IA_Zoom
      - Value Type: Axis1D (float)
      
   c) Name: IA_RightClickPan
      - Value Type: Digital (bool)

4. CREATE INPUT MAPPING CONTEXT:
   - Content Browser > Right-click > Input > Input Mapping Context  
   - Name: IMC_PlanetCamera
   - Open it and add these mappings:
   
   IA_Move (Axis2D):
   
     W key:
       - Add Modifier: Swizzle Input Axis Values -> Order: YXZ
       
     S key:
       - Add Modifier: Swizzle Input Axis Values -> Order: YXZ
       - Add Modifier: Negate (separate modifier)
       
     D key:
       - Add Modifier: Swizzle Input Axis Values -> Order: XYZ
       
     A key:
       - Add Modifier: Swizzle Input Axis Values -> Order: XYZ
       - Add Modifier: Negate (separate modifier)
       
     (Repeat same setup for Arrow keys: Up=W, Down=S, Right=D, Left=A)
   
   IA_Zoom:
     - Mouse Wheel Axis (no modifiers needed)
   
   IA_RightClickPan:
     - Right Mouse Button (no modifiers needed)

5. CONFIGURE THE CAMERA PAWN:
   - Find PlanetCameraPawn in Content Browser (enable Show C++ Classes)
   - Drag it into the level
   - In Details panel, under "Input" category:
     - Set Input Mapping Context = IMC_PlanetCamera
     - Set Move Action = IA_Move
     - Set Zoom Action = IA_Zoom  
     - Set Right Click Pan Action = IA_RightClickPan

NOTE: This is much simpler than the old instructions!
The deprecation warning is gone.


STEP 3: CREATE THE PLANET LEVEL
===========================================

1. Create a new level: File > New Level > Empty Level

2. SETUP GAMEMODE:
   - Window > World Settings
   - Under "Game Mode" section
   - Set "GameMode Override" to "PlanetConquestGameMode"
   - You'll see "Default Pawn Class" automatically shows PlanetCameraPawn

3. CREATE CAMERA BLUEPRINT (to assign input assets):
   - In Content Browser, find "PlanetCameraPawn" (C++ Classes > Planet_Conquest)
   - Right-click > Create Blueprint class based on PlanetCameraPawn
   - Name it: BP_PlanetCamera
   - Open BP_PlanetCamera
   - In Details panel, find "Input" category
   - Assign these:
     * Input Mapping Context = IMC_PlanetCamera
     * Move Action = IA_Move
     * Zoom Action = IA_Zoom
     * Right Click Pan Action = IA_RightClickPan
   - Compile and Save

4. CREATE GAMEMODE BLUEPRINT (to use our camera blueprint):
   - In Content Browser, find "PlanetConquestGameMode" (C++ Classes > Planet_Conquest)
   - Right-click > Create Blueprint class based on PlanetConquestGameMode
   - Name it: BP_PlanetGameMode
   - Open BP_PlanetGameMode
   - In Details panel, find "Classes" section
   - Set "Default Pawn Class" to BP_PlanetCamera
   - Compile and Save

5. UPDATE WORLD SETTINGS:
   - Back in World Settings
   - Change "GameMode Override" to BP_PlanetGameMode (not the C++ version)

6. ADD THE PLANET:
   - In Content Browser, find "PlanetActor" (C++ Classes > Planet_Conquest)
   - Drag it into the level

The camera should be looking down at a sphere (your planet) from a top-down RTS perspective!

EXPECTED VIEW:
- Top-down angled camera (like Spore civ stage)
- Spherical planet below
- You can pan around to explore
- Zoom in/out to adjust view distance
   - In Place Actors panel, search "Player Start"
   - Drag into level
   - Position it at (0, 0, 6000) - above the planet

8. Save the level as "PlanetTestMap"

9. Press Play!


STEP 4: TEST THE CONTROLS
===========================================

Once in Play mode, you should be able to:

✓ WASD or Arrow Keys - Pan the camera around
✓ Mouse to screen edges - Edge scrolling (move mouse to edge of screen)
✓ Right-click + Drag - Pan the camera
✓ Mouse wheel - Zoom in/out
✓ Q/E keys - Alternative zoom controls

The camera should be looking down at a sphere (your planet) from a top-down RTS perspective!


TROUBLESHOOTING:
===========================================

Camera not moving?
- Check that input mappings are set up correctly
- Make sure GameMode is set to PlanetConquestGameMode
- Check Output Log for errors

Can't see planet?
- Make sure PlanetActor is at (0, 0, 0)
- Try zooming out with mouse wheel
- Check camera's starting position (should spawn at player start)

No player start?
- Add a Player Start actor to the level
- Position it above the planet (e.g., at Z = 6000)


===========================================
STEP 7: CREATE YELLOW WIREFRAME SELECTION MATERIAL
===========================================

To make selection boxes appear as yellow wireframes:

1. In Content Browser, navigate to Content/ (root folder)
2. Right-click > Materials > Material
3. Name it: M_SelectionBox_Yellow
4. Open the material

5. In the Details panel (left side):
   - Shading Model: Unlit
   - Blend Mode: Translucent
   - Enable "Wireframe" checkbox

6. In the material graph:
   a) Create a Constant3Vector node (Right-click > Constant3Vector)
      - Set RGB to: R=1, G=1, B=0 (bright yellow)
   
   b) Create a Multiply node
      - Connect the yellow Constant3Vector to A
      - Create a Constant node with value 3.0
      - Connect to B (this makes it brighter)
   
   c) Connect the Multiply output to Emissive Color input
   
   d) Create a Constant node with value 0.9
      - Connect to Opacity

7. Click Apply and Save
8. Close the material editor

9. Recompile the game (the code will automatically load this material)

If you don't create this material, selection boxes will use default gray material.


===========================================
STEP 8: CREATE CITY UI WIDGET (WBP_CityUI)
===========================================

To enable the city management UI:

1. COMPILE THE CODE FIRST (if you haven't already)
   - Close editor, reopen to load new CityWidget class

2. CREATE THE WIDGET BLUEPRINT:
   - Content Browser > Right-click > User Interface > Widget Blueprint
   - Name it: WBP_CityUI
   - Open the widget

3. ADD A BUTTON:
   - From the Palette (left side), drag a "Button" onto the canvas
   - Position it where you want (e.g., top-right corner)
   - Set Anchors: Top-Right (so it stays in corner when screen resizes)
   - Rename the button to "SpawnVehicleButton" (optional but helpful)

4. ADD TEXT TO THE BUTTON:
   - Drag a "Text" widget from Palette onto the Button (as a child)
   - In Details panel, set Text to: "Spawn Vehicle"
   - Adjust font size if needed (e.g., 16-24)

5. ENABLE BUTTON AS VARIABLE (IMPORTANT!):
   - Select the Button in the Hierarchy
   - At the top of Details panel, check "Is Variable" checkbox
   - Now events will be available!

6. BIND THE BUTTON CLICK EVENT:
   OPTION A (Events Panel):
   - With button still selected, scroll down in Details panel to "Events" section
   - Find "On Clicked" and click the green "+" button
   - This opens the Event Graph

   OPTION B (Event Graph directly):
   - Go to the "Graph" tab at top
   - Right-click > Add Event > Add Event On Clicked (SpawnVehicleButton)

7. CONNECT THE EVENT TO C++ FUNCTION:
   - In the Event Graph, you should see "On Clicked (SpawnVehicleButton)" node
   - Drag from the execution pin (white arrow)
   - Search for "OnSpawnVehicleClicked" (this is the C++ function)
   - Connect them together
   - Compile and Save the widget

8. ASSIGN WIDGET TO PLAYER CONTROLLER:
   - Open the World Settings panel (Window > World Settings)
   - In "Game Mode" section, set:
     * Game Mode Override: PlanetConquestGameMode (should already be set)
     * Player Controller Class: PlanetConquestPlayerController
   
   - In the World Outliner or Level viewport, find the Player Controller
     (It might auto-spawn, or you may need to place it)
   
   - Select the Player Controller instance
   - In Details panel, find "City Widget Class" property
   - Set it to: WBP_CityUI (the widget you just created)

ALTERNATIVE WAY TO SET PLAYER CONTROLLER:
   - Create or edit Blueprint based on PlanetConquestPlayerController
   - Set City Widget Class as default value in Blueprint
   - Use that Blueprint as Player Controller Class in Game Mode


9. TEST IT:
   - Press Play
   - Click on the city (the ring) - UI should appear in corner
   - Click "Spawn Vehicle" button - new vehicle should spawn near city
   - Click multiple times - multiple vehicles spawn
   - Click away from city - UI should hide
   - Click on vehicle or resource - UI should hide

TROUBLESHOOTING:
   - Button has no events? Check "Is Variable" checkbox
   - Widget doesn't appear? Check Output Log for "CityWidgetClass not set!"
   - Button doesn't work? Make sure you connected OnClicked to OnSpawnVehicleClicked
   - Vehicle spawns in wrong place? Check VehicleSpawnRadius in CityActor (default 500)
