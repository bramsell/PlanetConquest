## Your Goal-Oriented Architecture Idea

Yes, this is exactly the right direction. What you're describing is **Goal-Oriented Action Planning (GOAP)** or a simplified **Hierarchical Task Network**. Here's how it maps:

```
GOALS (what I want)
  ├── ConquerEnemy (long-term, strategic)
  ├── DefendTerritory (reactive, urgent)
  ├── EconomicDominance (long-term, passive)
  └── Survive (emergency)

PROBLEMS (what's threatening my goals)
  ├── UnderAttack → threatens DefendTerritory, Survive
  ├── LowIncome → threatens all goals (can't do anything)
  ├── WeakMilitary → threatens ConquerEnemy
  └── EnemyExpanding → threatens EconomicDominance

PLANS (sequences of actions to achieve goals)
  ConquerEnemy:
    1. IF money < threshold → CaptureResources, BuildFactories
    2. IF vehicles < AssessEnemyCity().VehiclesNeeded → BuildVehicles
    3. IF vehicles >= needed → ExecuteAttack
    
  DefendTerritory:
    1. IF under_active_attack → Recall vehicles, build turrets
    2. IF incoming_threat → Position defenders
    3. ELSE → Patrol/hold
```

The key insight: **actions are means to goals, not independent utilities**.

### Goal Selection with Blocked Goal Handling:

```cpp
void AAITeamController::SelectPrimaryGoal()
{
    // Sort by priority
    Goals.Sort([](const FGoalState& A, const FGoalState& B)
    {
        return A.Priority > B.Priority;
    });
    
    // Try to select highest priority UNBLOCKED goal
    PrimaryGoal = EStrategicGoal::None;
    
    for (const FGoalState& Goal : Goals)
    {
        if (!Goal.bIsBlocked && Goal.Priority > 0.1f)
        {
            PrimaryGoal = Goal.Goal;
            PrimaryGoalState = Goal;
            break;
        }
    }
    
    // If all goals are blocked, select the blocked goal with highest priority
    // and work on UNBLOCKING it
    if (PrimaryGoal == EStrategicGoal::None && Goals.Num() > 0)
    {
        PrimaryGoal = Goals[0].Goal;
        PrimaryGoalState = Goals[0];
        bWorkingOnBlockedGoal = true;
    }
    else
    {
        bWorkingOnBlockedGoal = false;
    }
    
    if (ControlledTeam == EOwnerTeam::AI1)
    {
        UE_LOG(LogTemp, Warning, TEXT("[AI TEAM 2] === GOAL SELECTION ==="));
        for (const FGoalState& G : Goals)
        {
            UE_LOG(LogTemp, Warning, TEXT("  %s: Priority=%.1f %s %s"),
                *GoalToString(G.Goal), G.Priority,
                G.bIsBlocked ? TEXT("[BLOCKED]") : TEXT(""),
                G.bIsBlocked ? *G.BlockReason : TEXT(""));
        }
        UE_LOG(LogTemp, Warning, TEXT("  -> Selected: %s %s"),
            *GoalToString(PrimaryGoal),
            bWorkingOnBlockedGoal ? TEXT("(working to unblock)") : TEXT(""));
    }
}
```

```cpp
void AAITeamController::GeneratePlan()
{
    CurrentPlan.Goal = PrimaryGoal;
    CurrentPlan.ActionSequence.Empty();
    CurrentPlan.CurrentStep = 0;
    
    switch (PrimaryGoal)
    {
    case EStrategicGoal::Survive:
        // Emergency mode: defend at all costs
        CurrentPlan.ActionSequence.Add(EAIAction::DefendCities);
        if (Money >= 2000)
        {
            CurrentPlan.ActionSequence.Add(EAIAction::BuildTurrets);
        }
        break;
        
    case EStrategicGoal::DefendTerritory:
        CurrentPlan.ActionSequence.Add(EAIAction::DefendCities);
        // If we have extra money and are under heavy attack, add turrets
        if (Money >= 2000 && Pressures.CitiesUnderActiveAttack > 0)
        {
            CurrentPlan.ActionSequence.Add(EAIAction::BuildTurrets);
        }
        break;
        
    case EStrategicGoal::ConquerEnemy:
        if (bWorkingOnBlockedGoal)
        {
            // We want to attack but don't have enough force
            // Plan: build army first
            if (Money < PrimaryGoalState.MoneyNeeded && Pressures.ProximalResources > 0)
            {
                // Need money -> capture resources first
                CurrentPlan.ActionSequence.Add(EAIAction::CaptureResources);
            }
            if (Money >= 1000)
            {
                // Have some money -> build vehicles
                CurrentPlan.ActionSequence.Add(EAIAction::BuildVehicles);
            }
        }
        else
        {
            // Ready to attack!
            CurrentPlan.ActionSequence.Add(EAIAction::CaptureCities);
            // Also capture resources opportunistically with spare vehicles
            if (Pressures.ProximalResources > 0)
            {
                CurrentPlan.ActionSequence.Add(EAIAction::CaptureResources);
            }
        }
        break;
        
    case EStrategicGoal::EconomicGrowth:
        // Capture resources, build factories
        if (Pressures.ProximalResources > 0)
        {
            CurrentPlan.ActionSequence.Add(EAIAction::CaptureResources);
        }
        if (Money >= 3000)
        {
            CurrentPlan.ActionSequence.Add(EAIAction::BuildFactories);
        }
        // Aggressive expansion if we're greedy and have vehicles
        if (Personality.Greed > 0.6f && Pressures.NonProximalResources > 0 && Pressures.VehiclesOwned > 5)
        {
            CurrentPlan.ActionSequence.Add(EAIAction::CaptureEnemyResources);
        }
        break;
        
    case EStrategicGoal::MilitaryBuildup:
        // Focus on building army
        if (Money < 1000 && Pressures.ProximalResources > 0)
        {
            // Need income first
            CurrentPlan.ActionSequence.Add(EAIAction::CaptureResources);
        }
        if (Money >= 1000)
        {
            CurrentPlan.ActionSequence.Add(EAIAction::BuildVehicles);
        }
        // Consider factory if we're going to need sustained production
        if (Money >= 3000 && PrimaryGoalState.VehiclesNeeded > 10)
        {
            CurrentPlan.ActionSequence.Add(EAIAction::BuildFactories);
        }
        break;
        
    default:
        // Fallback: economic activity
        CurrentPlan.ActionSequence.Add(EAIAction::CaptureResources);
        break;
    }
    
    if (ControlledTeam == EOwnerTeam::AI1)
    {
        UE_LOG(LogTemp, Warning, TEXT("[AI TEAM 2] === PLAN for %s ==="), *GoalToString(PrimaryGoal));
        for (int32 i = 0; i < CurrentPlan.ActionSequence.Num(); i++)
        {
            UE_LOG(LogTemp, Warning, TEXT("  Step %d: %s"), i + 1, *ActionToString(CurrentPlan.ActionSequence[i]));
        }
    }
}
```

```cpp
void AAITeamController::AllocateResourcesToGoal()
{
    TArray<AVehicleActor*> AvailableVehicles = GetTeamVehicles();
    int32 TotalVehicles = AvailableVehicles.Num();
    
    // Reset all allocations
    for (auto& Pair : Actions)
    {
        Pair.Value.CurrentVehicles = 0;
        Pair.Value.AllocatedMoney = 0;
        Pair.Value.bCanExecute = false;
    }
    
    // Allocate based on plan actions (in order of plan sequence)
    int32 VehiclesRemaining = TotalVehicles;
    int32 MoneyRemaining = Money;
    
    for (EAIAction Action : CurrentPlan.ActionSequence)
    {
        FActionPriority& Priority = Actions[Action];
        
        bool bIsBuildingAction = (Action == EAIAction::BuildVehicles || 
                                  Action == EAIAction::BuildTurrets || 
                                  Action == EAIAction::BuildFactories);
        
        if (bIsBuildingAction)
        {
            // Building actions get money allocation
            int32 ActionCost = GetActionCost(Action);
            if (MoneyRemaining >= ActionCost)
            {
                Priority.AllocatedMoney = ActionCost;
                Priority.bCanExecute = true;
                MoneyRemaining -= ActionCost;
            }
        }
        else
        {
            // Vehicle actions get vehicle allocation
            int32 ToAllocate = FMath::Min(VehiclesRemaining, Priority.MaxVehicles);
            ToAllocate = FMath::Max(ToAllocate, Priority.MinVehicles);
            
            if (ToAllocate >= Priority.MinVehicles && VehiclesRemaining >= ToAllocate)
            {
                Priority.CurrentVehicles = ToAllocate;
                Priority.bCanExecute = true;
                VehiclesRemaining -= ToAllocate;
            }
        }
    }
}

int32 AAITeamController::GetActionCost(EAIAction Action)
{
    switch (Action)
    {
    case EAIAction::BuildVehicles: return 1000;
    case EAIAction::BuildTurrets: return 2000;
    case EAIAction::BuildFactories: return 3000;
    default: return 0;
    }
}
```

## Why This Is Emergent

The emergent behavior comes from:

1. **Goal dependencies create natural sequencing** - "I want to attack" → "I'm blocked (not enough vehicles)" → "My new goal is military buildup" → "I need money for vehicles" → "Capture resources" → eventually "Now I have enough, attack!"

2. **Personality affects goal priorities, not action weights** - An aggressive AI prioritizes ConquerEnemy higher, so it starts building toward attack sooner. A greedy AI prioritizes EconomicGrowth, so it expands resources before attacking.

3. **Blocked goals don't disappear** - The AI remembers "I WANT to attack that city" while working on prerequisites. This creates sustained intent rather than tick-by-tick recalculation.

4. **Plans can be interrupted** - If DefendTerritory suddenly spikes (enemy attack), it overrides ConquerEnemy mid-buildup. But once the threat passes, the AI returns to its previous goal.

5. **The AI can "explain" its behavior** - You can log "Goal: ConquerEnemy (blocked: need 8 vehicles, have 4) → Plan: BuildVehicles" and understand exactly why it's building.

## The Multi-Goal Balance Problem

Your instinct is correct: real strategic thinking isn't "pick one goal, ignore others." It's "I want several things, some conflict, some synergize, how do I navigate?"

Here's the insight: **actions can serve multiple goals simultaneously**. Instead of goals → plans → actions, think of it as:

```
ACTIONS → which goals do they advance?

CaptureResources:
  ✓ EconomicGrowth (+income)
  ✓ MilitaryBuildup (enables vehicle production)
  ✓ ConquerEnemy (indirectly, via buildup)
  ○ DefendTerritory (neutral)

BuildVehicles:
  ✓ MilitaryBuildup (directly)
  ✓ ConquerEnemy (enables attack)
  ✓ DefendTerritory (more defenders)
  ✗ EconomicGrowth (costs money)

CaptureEnemyResources:
  ✓ EconomicGrowth (income + denies enemy)
  ✓ ConquerEnemy (weakens enemy economy)
  ✗ DefendTerritory (vehicles away from home)

BuildTurrets:
  ✓ DefendTerritory (directly)
  ✗ ConquerEnemy (money not going to vehicles)
  ✗ EconomicGrowth (money not going to factories)
```

Now the decision becomes: **given my current goal weights, which action serves the best combination?**

## A Simpler Architecture: Goal-Weighted Action Scoring

Instead of goals selecting plans, goals **vote** on actions:

```cpp
struct FGoalContribution
{
    EStrategicGoal Goal;
    float Weight;           // How important is this goal right now? (0-1)
    float Contribution;     // How much does this action help? (-1 to +1)
};

float AAITeamController::ScoreActionForGoals(EAIAction Action)
{
    float TotalScore = 0.0f;
    
    for (const FGoalState& Goal : ActiveGoals)
    {
        float Contribution = GetActionContribution(Action, Goal.Goal);
        TotalScore += Goal.Weight * Contribution;
    }
    
    return TotalScore;
}
```

```cpp
        case EAIAction::CaptureEnemyResources: return 0.5f; // Weakens enemy + funds us
```

```cpp
void AAITeamController::CalculateGoalWeights()
{
    ActiveGoals.Empty();
    
    // DEFEND - based on active threats
    FGoalState Defend;
    Defend.Goal = EStrategicGoal::DefendTerritory;
    Defend.Weight = 0.1f;  // Baseline
    
    if (Pressures.CitiesUnderActiveAttack > 0)
    {
        Defend.Weight += 0.5f;  // Major boost when under attack
    }
    Defend.Weight += (1.0f - Pressures.LowestCityHealthPercent) * 0.3f;  // Vulnerable cities
    Defend.Weight *= (0.7f + Personality.Defensiveness * 0.6f);  // Personality modifier
    ActiveGoals.Add(Defend);
    
    // CONQUER - based on opportunity and strength
    FGoalState Conquer;
    Conquer.Goal = EStrategicGoal::ConquerEnemy;
    Conquer.Weight = 0.1f;  // Baseline
    
    // Find best target assessment
    FCityAssessment BestTarget = FindBestAttackTarget();
    if (BestTarget.City && BestTarget.ConfidenceRatio >= 1.0f)
    {
        // We CAN attack - boost weight
        Conquer.Weight += 0.4f * BestTarget.ConfidenceRatio;
    }
    Conquer.Weight *= (0.5f + Personality.Aggression * 1.0f);  // Personality
    ActiveGoals.Add(Conquer);
    
    // ECONOMIC - based on opportunity and need
    FGoalState Economy;
    Economy.Goal = EStrategicGoal::EconomicGrowth;
    Economy.Weight = 0.2f;  // Baseline (economy is always somewhat important)
    
    if (Pressures.ProximalResources > 0)
    {
        Economy.Weight += Pressures.ProximalResources * 0.1f;  // Uncaptured resources
    }
    if (Money < 2000)
    {
        Economy.Weight += 0.3f;  // Low money = prioritize income
    }
    Economy.Weight *= (0.6f + Personality.Greed * 0.8f);  // Personality
    ActiveGoals.Add(Economy);
    
    // BUILDUP - based on military gap
    FGoalState Buildup;
    Buildup.Goal = EStrategicGoal::MilitaryBuildup;
    Buildup.Weight = 0.1f;  // Baseline
    
    // If we want to attack but can't, buildup becomes important
    if (BestTarget.City && BestTarget.ConfidenceRatio < 1.0f)
    {
        // Gap between what we have and what we need
        float Gap = 1.0f - BestTarget.ConfidenceRatio;
        Buildup.Weight += Gap * 0.5f;
    }
    Buildup.Weight *= (0.5f + Personality.Aggression * 0.5f);
    ActiveGoals.Add(Buildup);
    
    // Normalize weights to sum to 1.0
    float TotalWeight = 0.0f;
    for (const FGoalState& G : ActiveGoals)
    {
        TotalWeight += G.Weight;
    }
    if (TotalWeight > 0.0f)
    {
        for (FGoalState& G : ActiveGoals)
        {
            G.Weight /= TotalWeight;
        }
    }
}
```

### Action Selection: Best Composite Score

```cpp
void AAITeamController::SelectActions()
{
    // Score each action based on all goal contributions
    TMap<EAIAction, float> ActionScores;
    
    for (auto& Pair : Actions)
    {
        EAIAction Action = Pair.Key;
        float Score = ScoreActionForGoals(Action);
        
        // Apply feasibility modifiers
        Score *= GetFeasibilityMultiplier(Action);
        
        ActionScores.Add(Action, Score);
    }
    
    // Sort actions by score
    TArray<EAIAction> SortedActions;
    ActionScores.GetKeys(SortedActions);
    SortedActions.Sort([&ActionScores](const EAIAction& A, const EAIAction& B)
    {
        return ActionScores[A] > ActionScores[B];
    });
    
    // Allocate resources to top actions
    int32 VehiclesRemaining = GetTeamVehicles().Num();
    int32 MoneyRemaining = Money;
    
    for (EAIAction Action : SortedActions)
    {
        if (ActionScores[Action] <= 0.0f)
        {
            continue;  // Skip negative-value actions
        }
        
        FActionPriority& Priority = Actions[Action];
        
        if (IsVehicleAction(Action))
        {
            int32 ToAllocate = FMath::Min(VehiclesRemaining, Priority.MaxVehicles);
            if (ToAllocate >= Priority.MinVehicles)
            {
                Priority.CurrentVehicles = ToAllocate;
                Priority.bCanExecute = true;
                VehiclesRemaining -= ToAllocate;
            }
        }
        else  // Building action
        {
            int32 Cost = GetActionCost(Action);
            if (MoneyRemaining >= Cost)
            {
                Priority.AllocatedMoney = Cost;
                Priority.bCanExecute = true;
                MoneyRemaining -= Cost;
            }
        }
    }
}

float AAITeamController::GetFeasibilityMultiplier(EAIAction Action)
{
    switch (Action)
    {
    case EAIAction::CaptureCities:
        {
            // Can't attack if we don't have enough force
            FCityAssessment Target = FindBestAttackTarget();
            if (!Target.City || Target.ConfidenceRatio < 0.7f)
            {
                return 0.0f;  // Not feasible
            }
            return FMath::Clamp(Target.ConfidenceRatio - 0.7f, 0.0f, 1.0f);
        }
        
    case EAIAction::CaptureResources:
        if (Pressures.ProximalResources == 0)
        {
            return 0.0f;  // Nothing to capture
        }
        return 1.0f;
        
    case EAIAction::BuildVehicles:
        if (Money < 1000)
        {
            return 0.0f;  // Can't afford
        }
        return 1.0f;
        
    case EAIAction::BuildFactories:
        if (Money < 3000)
        {
            return 0.0f;
        }
        return 1.0f;
        
    case EAIAction::BuildTurrets:
        if (Money < 2000)
        {
            return 0.0f;
        }
        return 1.0f;
        
    default:
        return 1.0f;
    }
}
```

## The "Best of Both Worlds" Insight

Here's what makes this elegant: **actions that serve multiple goals naturally rise to the top**.

Example scenario:
- Goal weights: ConquerEnemy=0.3, EconomicGrowth=0.3, MilitaryBuildup=0.25, DefendTerritory=0.15

Action scores:
```

  ConquerEnemy:    0.3 × 0.3 = 0.09
  EconomicGrowth:  0.3 × 1.0 = 0.30
  MilitaryBuildup: 0.25 × 0.5 = 0.125
  DefendTerritory: 0.15 × 0.0 = 0.0
  TOTAL: 0.515 ★ (serves 3 goals!)

BuildVehicles:
  ConquerEnemy:    0.3 × 0.7 = 0.21

  MilitaryBuildup: 0.25 × 1.0 = 0.25
  DefendTerritory: 0.15 × 0.5 = 0.075
```

CaptureResources wins because it **advances the most goals simultaneously**. The AI naturally discovers "I should build economy before attacking" without explicit sequencing rules.

## The Sequencing Emerges Naturally

Watch what happens over time:

**Turn 1:** AI has 3 vehicles, needs 8 to attack
- ConquerEnemy weight is low (infeasible)
- MilitaryBuildup weight is high (want to attack, can't yet)
- EconomicGrowth weight is medium
- Result: CaptureResources and BuildVehicles score highest

**Turn 5:** AI now has 6 vehicles, $4000
- MilitaryBuildup still high, but smaller gap now
- ConquerEnemy starting to become feasible (confidence 0.75)
- Result: BuildVehicles still wins, but margin is shrinking

**Turn 8:** AI has 9 vehicles, confidence ratio 1.3
- ConquerEnemy weight spikes (opportunity!)
- MilitaryBuildup weight drops (we have enough)
- Result: CaptureCities wins, attack commences

**Turn 10:** Enemy counterattacks our city
- DefendTerritory weight spikes
- ConquerEnemy drops (vehicles needed at home)
- Result: DefendCities wins, attack pauses

**Turn 12:** Threat eliminated
- DefendTerritory drops
- ConquerEnemy returns to high
- Result: Resume attack

**No explicit state machine. No hardcoded sequences.** The behavior emerges from goal weights and action contributions.

## Handling Conflicts

You asked about conflicting goals. The contribution system handles this naturally:

**ConquerEnemy vs DefendTerritory:**
- BuildTurrets: +0.8 for Defend, -0.3 for Conquer → net depends on weights
- BuildVehicles: +0.5 for Defend, +0.7 for Conquer → serves both!
- CaptureCities: -0.4 for Defend, +1.0 for Conquer → only wins if Conquer dominates

An AI with both goals active will naturally build vehicles (serves both) rather than turrets (serves one, hurts other).

**EconomicGrowth vs MilitaryBuildup:**
- CaptureResources: +1.0 for Economy, +0.5 for Buildup → synergy!
- BuildVehicles: -0.3 for Economy, +1.0 for Buildup → tension
- BuildFactories: +0.9 for Economy, +0.4 for Buildup → synergy!

An AI pursuing both will prefer resource capture and factories over pure vehicle spam.

## Goal Sources: Opportunity, Desperation, Personality

Goals come from all three, but with different characteristics:

| Source | Characteristics | Examples |
|--------|----------------|----------|
| **Desperation** | Binary/threshold, overrides everything, non-negotiable | City under attack → DefendTerritory spikes. No vehicles → MilitaryBuildup critical. Last city at 20% HP → Survive mode. |
| **Opportunity** | Situational, fades when window closes, creates urgency | Enemy city weak + we're strong → ConquerEnemy spikes. Lots of uncaptured proximal resources → EconomicGrowth rises. Enemy distracted fighting someone else → attack window. |
| **Personality** | Baseline bias, always present, modulates other sources | Aggressive AI has higher ConquerEnemy floor. Greedy AI has higher EconomicGrowth floor. Cautious AI has higher DefendTerritory floor. |

The math looks like:

```cpp
GoalWeight = BaslineFromPersonality + OpportunityBonus + DesperationSpike
```

Where desperation spikes are **multiplicative** (they dominate) and opportunity is **additive** (it shifts preferences but doesn't override survival).

```cpp

{
```

```cpp
    TSet<EOwnerTeam> ActiveTeams = GetActiveTeams();
    
    for (EOwnerTeam OtherTeam : ActiveTeams)
    {
        if (OtherTeam == ControlledTeam || OtherTeam == EOwnerTeam::Neutral)
            continue;
        
        FTeamRelationship& Rel = Relationships.FindOrAdd(OtherTeam);
        ERelationshipStatus Status = Rel.GetStatus();
        
        // Calculate opportunity/threat from this specific team
        FTeamAssessment Assessment = AssessTeam(OtherTeam);
        
        switch (Status)
        {
        case ERelationshipStatus::War:
            {
                // CONQUER goal - we want to destroy them
                FStrategicGoal Conquer;
                Conquer.Type = EStrategicGoalType::Conquer;
                Conquer.TargetTeam = OtherTeam;
                
                // Weight based on: can we win? + how much do we hate them?
                float Hostility = FMath::Abs(Rel.RelationshipValue) / 100.0f;
                float Opportunity = Assessment.OurStrengthRatio;  // >1 means we're stronger
                
                Conquer.Weight = (Personality.Aggression * 0.3f) + 
                                 (Hostility * 0.3f) + 
                                 (Opportunity * 0.4f);
                
                // Desperation: if they're about to destroy us, prioritize them
                if (Assessment.TheyAreAttackingUs)
                {
                    Conquer.Weight += 1.0f;
                }
                
                ActiveGoals.Add(Conquer);
            }
            break;
            
        case ERelationshipStatus::Hostile:
            {
                // WEAKEN goal - hurt them without full commitment
                FStrategicGoal Weaken;
                Weaken.Type = EStrategicGoalType::Weaken;
                Weaken.TargetTeam = OtherTeam;
                
                // Opportunistic - only if low risk
                float Opportunity = FMath::Max(0.0f, Assessment.OurStrengthRatio - 1.0f);
                Weaken.Weight = Opportunity * 0.5f * (0.5f + Personality.Aggression * 0.5f);
                
                ActiveGoals.Add(Weaken);
                
                // CONTAIN goal - stop them from expanding toward us
                FStrategicGoal Contain;
                Contain.Type = EStrategicGoalType::Contain;
                Contain.TargetTeam = OtherTeam;
                Contain.Weight = 0.2f + (Rel.Fear / 100.0f) * 0.3f;
                
                ActiveGoals.Add(Contain);
            }
            break;
            
        case ERelationshipStatus::Neutral:
            {
                // Could go either way - opportunistic
                if (Assessment.OurStrengthRatio > 1.5f && Personality.Aggression > 0.6f)
                {
                    // We're much stronger and aggressive - consider attacking
                    FStrategicGoal Conquer;
                    Conquer.Type = EStrategicGoalType::Conquer;
                    Conquer.TargetTeam = OtherTeam;
                    Conquer.Weight = (Assessment.OurStrengthRatio - 1.0f) * 0.3f * Personality.Aggression;
                    ActiveGoals.Add(Conquer);
                }
                else
                {
                    // Maintain neutral - focus elsewhere
                    FStrategicGoal Coexist;
                    Coexist.Type = EStrategicGoalType::Coexist;
                    Coexist.TargetTeam = OtherTeam;
                    Coexist.Weight = 0.1f + Personality.Caution * 0.2f;
                    ActiveGoals.Add(Coexist);
                }
            }
            break;
            
        case ERelationshipStatus::Friendly:
            {
                // Maintain friendship
                FStrategicGoal Coexist;
                Coexist.Type = EStrategicGoalType::Coexist;
                Coexist.TargetTeam = OtherTeam;
                Coexist.Weight = 0.3f + (Rel.RelationshipValue / 100.0f) * 0.3f;
                ActiveGoals.Add(Coexist);
            }
            break;
            
        case ERelationshipStatus::Allied:
            {
                // Active cooperation

                Ally.Type = EStrategicGoalType::Ally;
                Ally.TargetTeam = OtherTeam;
                Ally.Weight = 0.5f;
```

```cpp
TArray<FActionConsequence> AAITeamController::PredictActionConsequences(EAIAction Action, EOwnerTeam TargetTeam)
{

    switch (Action)
    {
    case EAIAction::CaptureCities:

            FActionConsequence Direct;
            Direct.AffectedTeam = TargetTeam;
            Direct.RelationshipChange = -30.0f;
            Consequences.Add(Direct);

            for (EOwnerTeam AllyTeam : GetAlliesOf(TargetTeam))

                FActionConsequence Indirect;
                Indirect.AffectedTeam = AllyTeam;
                Indirect.RelationshipChange = -15.0f;
                Consequences.Add(Indirect);

            for (EOwnerTeam EnemyTeam : GetEnemiesOf(TargetTeam))
            {

                {
                    FActionConsequence Opportunistic;
                    Opportunistic.AffectedTeam = EnemyTeam;
                    Opportunistic.RelationshipChange = +5.0f;
                    Consequences.Add(Opportunistic);
                }
            }
        }
```

```cpp
    {
        FTeamRelationship& Rel = Relationships.FindOrAdd(C.AffectedTeam);
        
        // How much do we CARE about this relationship?
        float RelationshipValue = 0.0f;
        
        ERelationshipStatus Status = Rel.GetStatus();
        switch (Status)
        {
        case ERelationshipStatus::Allied:
            RelationshipValue = 1.0f;  // Highly value this relationship
            break;
        case ERelationshipStatus::Friendly:
            RelationshipValue = 0.6f;
            break;
        case ERelationshipStatus::Neutral:
            RelationshipValue = 0.3f;
            break;
        case ERelationshipStatus::Hostile:
            RelationshipValue = 0.1f;  // Don't care much
            break;
        case ERelationshipStatus::War:
            RelationshipValue = 0.0f;  // Don't care at all
            break;
        }
        
        // Personality affects how much we care about relationships generally
        RelationshipValue *= (0.5f + Personality.Caution * 0.5f);  // Cautious = diplomatic
        
        // Calculate cost of damaging this relationship
        if (C.RelationshipChange < 0.0f)
        {
            RelationshipCost += FMath::Abs(C.RelationshipChange) * RelationshipValue * 0.01f;
        }
        else
        {
            // Bonus for improving relationships
            RelationshipCost -= C.RelationshipChange * RelationshipValue * 0.005f;
        }
    }
    
    return GoalScore - RelationshipCost;
}
```

```cpp
void AAITeamController::RecordDangerZone(FVector Location)
{
    // Check if near existing danger zone
    for (FDangerZone& Zone : DangerZones)
    {
        if (FVector::Dist(Zone.Location, Location) < Zone.Radius)
        {
            // Reinforce existing zone
            Zone.DangerLevel = FMath::Min(Zone.DangerLevel + 0.5f, 3.0f);
            Zone.Timestamp = CurrentWorldTime;
            return;
        }
    }
    
    // New danger zone
    FDangerZone NewZone;
    NewZone.Location = Location;
    NewZone.DangerLevel = 1.0f;
    NewZone.Timestamp = CurrentWorldTime;
    DangerZones.Add(NewZone);
}

void AAITeamController::UpdateDangerZones()
{
    // Decay danger over time (forget old threats)
    float DecayRate = 0.01f;  // Per second
    
    for (int32 i = DangerZones.Num() - 1; i >= 0; i--)
    {
        float Age = CurrentWorldTime - DangerZones[i].Timestamp;
        DangerZones[i].DangerLevel -= DecayRate * AIUpdateInterval;
        
        if (DangerZones[i].DangerLevel <= 0.0f)
        {
            DangerZones.RemoveAt(i);
        }
    }
}

float AAITeamController::GetLocationDanger(FVector Location)
{
    float TotalDanger = 0.0f;
    
    for (const FDangerZone& Zone : DangerZones)
    {
        float Distance = FVector::Dist(Location, Zone.Location);
        if (Distance < Zone.Radius)
        {
            // Danger falls off with distance
            float Proximity = 1.0f - (Distance / Zone.Radius);
            TotalDanger += Zone.DangerLevel * Proximity;
        }
    }
    
    return TotalDanger;
}
```

```cpp
        EAIAction::AttackVehicles,
        EAIAction::DefendCities

                Config.AllocatedVehicles = ToAllocate;
                Config.bCanExecute = true;
                VehiclesRemaining -= ToAllocate;
            }
            // If not enough, don't allocate ANY (no suicide attacks)
            continue;
        }
        
        // Normal allocation based on score ratio
        float ScoreRatio = ActionScores[Action] / GetTotalPositiveVehicleActionScore();
        int32 Ideal = FMath::RoundToInt(Pressures.VehiclesOwned * ScoreRatio);
        int32 ToAllocate = FMath::Clamp(Ideal, Config.MinVehicles, Config.MaxVehicles);
        ToAllocate = FMath::Min(ToAllocate, VehiclesRemaining);
        
        if (ToAllocate >= Config.MinVehicles)
        {
            Config.AllocatedVehicles = ToAllocate;
            Config.bCanExecute = true;
            VehiclesRemaining -= ToAllocate;
        }
    }
}
```

```cpp
void AAITeamController::AllocateBudget()
{
    // Money can buy: Vehicles, Turrets, Factories
    
    TArray<EAIAction> BuildingActions = {
        EAIAction::BuildVehicles,
        EAIAction::BuildTurrets,
        EAIAction::BuildFactories
    };
    
    // Calculate scores WITH affordability discounting
    TMap<EAIAction, float> AffordabilityScores;
    for (EAIAction Action : BuildingActions)
    {
        AffordabilityScores.Add(Action, ScoreActionWithAffordability(Action));
    }
    
    // Sort by affordability-adjusted score
    BuildingActions.Sort([&AffordabilityScores](const EAIAction& A, const EAIAction& B)
    {
        return AffordabilityScores[A] > AffordabilityScores[B];
    });
    
    // Reset allocations
    for (EAIAction Action : BuildingActions)
    {
        ActionConfigs[Action].AllocatedMoney = 0;
        ActionConfigs[Action].bCanExecute = false;
    }
    
    // Find best action and decide whether to spend or save
    if (BuildingActions.Num() == 0) return;
    
    EAIAction BestAction = BuildingActions[0];
    float BestScore = AffordabilityScores[BestAction];
    int32 BestCost = ActionConfigs[BestAction].Cost;
    
    if (BestScore <= 0.0f) return;  // Nothing worth buying
    
    if (Money >= BestCost)
    {
        // Can afford best action - do it
        ActionConfigs[BestAction].AllocatedMoney = BestCost;
        ActionConfigs[BestAction].bCanExecute = true;
    }
    else
    {
        // Saving for best action - log progress
        float Progress = (float)Money / (float)BestCost;
        
        if (bEnableDebugLogging)
        {
            UE_LOG(LogTemp, Log, TEXT("AI Team %d: Saving for %s ($%d/$%d = %.0f%%)"),
                (int32)ControlledTeam, *ActionToString(BestAction), Money, BestCost, Progress * 100.0f);
        }
    }
}
```

## The Core Idea: Beliefs + Learning + Varied Strategies

Instead of calculating the "correct" answer, the AI maintains **beliefs** about the world that may be wrong, and updates them based on experience. Different AIs can have different beliefs and try different approaches.

```cpp
USTRUCT()
struct FCombatBeliefs
{
    GENERATED_BODY()
    
    // "How many of my vehicles does it take to kill one enemy turret?"
    float VehiclesPerTurret = 2.0f;  // Initial guess
    
    // "How many of my vehicles does it take to kill one defender?"
    float VehiclesPerDefender = 1.2f;  // Initial guess (slight advantage to attacker)
    
    // "How much overkill do I need for safety?"
    float SafetyMultiplier = 1.3f;  // Initial guess
    
    // "How effective is chip damage?"
    float ChipDamageValue = 0.3f;  // 0 = worthless, 1 = as good as winning
    
    // "How fast do enemies rebuild?"
    float EnemyRebuildRate = 0.5f;  // Vehicles per minute estimate
    
    // Confidence in these beliefs (affects how quickly we update)
    float Confidence = 0.3f;  // Start uncertain
};

USTRUCT()
struct FEnemyTheory
{
    GENERATED_BODY()
    
    EOwnerTeam Enemy;
    
    // Per-enemy beliefs (may differ from global)
    FCombatBeliefs Beliefs;
    
    // Historical tracking
    TArray<FAttackRecord> AttackHistory;
    
    // Current assessment
    float LastKnownStrength = 0.0f;
    float LastAssessmentTime = 0.0f;
};

    ACityActor* TargetCity;

    int32 VehiclesSent;

    int32 DefendersObserved;
    float CityHealthAtStart;

    bool bSucceeded;
    int32 VehiclesLost;
    float DamageDealt;
    float CityHealthAtEnd;

        if (VehiclesSent == 0) return 0.0f;
        return DamageDealt / (float)VehiclesSent;

    {
        if (VehiclesSent == 0) return 0.0f;
        return 1.0f - ((float)VehiclesLost / (float)VehiclesSent);
    }
```

```cpp
void AAITeamController::UpdateBeliefsFromAttack(FEnemyTheory& Theory, const FAttackRecord& Record)
{
    FCombatBeliefs& Beliefs = Theory.Beliefs;
    
    // Learning rate: higher confidence = slower updates
    float LearningRate = 0.3f * (1.0f - Beliefs.Confidence * 0.5f);
    
    if (Record.bSucceeded)
    {
        // SUCCESS: Maybe we overestimated difficulty?
        
        float SurvivalRate = Record.GetVehicleSurvivalRate();
        
        if (SurvivalRate > 0.7f)
        {
            // Easy win - we sent too many, reduce estimates slightly
            Beliefs.VehiclesPerTurret *= (1.0f - LearningRate * 0.3f);
            Beliefs.SafetyMultiplier *= (1.0f - LearningRate * 0.2f);
        }
        else if (SurvivalRate > 0.4f)
        {
            // Close fight - estimates were about right
            Beliefs.Confidence += 0.1f;
        }
        else
        {
            // Pyrrhic victory - barely won, increase estimates
            Beliefs.VehiclesPerTurret *= (1.0f + LearningRate * 0.2f);
            Beliefs.SafetyMultiplier *= (1.0f + LearningRate * 0.1f);
        }
    }
    else
    {
        // FAILURE: We underestimated
        
        float DamageEfficiency = Record.GetDamagePerVehicle();
        
        if (Record.VehiclesLost == Record.VehiclesSent)
        {
            // Total wipe - severely underestimated
            Beliefs.VehiclesPerTurret *= (1.0f + LearningRate * 0.5f);
            Beliefs.VehiclesPerDefender *= (1.0f + LearningRate * 0.4f);
            Beliefs.SafetyMultiplier *= (1.0f + LearningRate * 0.3f);
            
            // Reduce confidence - our model is wrong
            Beliefs.Confidence *= 0.7f;
        }
        else if (DamageEfficiency > 50.0f)
        {
            // Did decent damage, just not enough force
            // Only increase safety multiplier
            Beliefs.SafetyMultiplier *= (1.0f + LearningRate * 0.2f);
        }
        else
        {
            // Poor damage efficiency - turrets/defenders stronger than expected
            if (Record.TurretsObserved > 0)
            {
                Beliefs.VehiclesPerTurret *= (1.0f + LearningRate * 0.3f);
            }
            if (Record.DefendersObserved > 0)
            {
                Beliefs.VehiclesPerDefender *= (1.0f + LearningRate * 0.3f);
            }
        }
        
        // Update chip damage value based on how useful partial damage was
        if (Record.DamageDealt > 0.0f && Record.CityHealthAtStart > 0.0f)
        {
            float DamageRatio = Record.DamageDealt / Record.CityHealthAtStart;
            // If we dealt 30%+ damage even in failure, chip damage is valuable
            if (DamageRatio > 0.3f)
            {
                Beliefs.ChipDamageValue = FMath::Lerp(Beliefs.ChipDamageValue, 0.6f, LearningRate);
            }
        }
    }
    
    // Clamp beliefs to reasonable ranges
    Beliefs.VehiclesPerTurret = FMath::Clamp(Beliefs.VehiclesPerTurret, 1.0f, 10.0f);
    Beliefs.VehiclesPerDefender = FMath::Clamp(Beliefs.VehiclesPerDefender, 0.5f, 5.0f);
    Beliefs.SafetyMultiplier = FMath::Clamp(Beliefs.SafetyMultiplier, 1.0f, 3.0f);
    Beliefs.ChipDamageValue = FMath::Clamp(Beliefs.ChipDamageValue, 0.0f, 1.0f);
    Beliefs.Confidence = FMath::Clamp(Beliefs.Confidence, 0.1f, 0.9f);
    
    UE_LOG(LogTemp, Log, TEXT("AI Team %d: Updated beliefs vs %d - VPT:%.1f, VPD:%.1f, Safety:%.1f, Chip:%.1f, Conf:%.0f%%"),
        (int32)ControlledTeam, (int32)Theory.Enemy,
        Beliefs.VehiclesPerTurret, Beliefs.VehiclesPerDefender, 
        Beliefs.SafetyMultiplier, Beliefs.ChipDamageValue, Beliefs.Confidence * 100.0f);
}
```

## Belief-Based Assessment

```cpp
FCityAssessment AAITeamController::AssessEnemyCity(ACityActor* City)
{
    FCityAssessment Assessment;
    Assessment.City = City;
    
    if (!City) return Assessment;
    
    EOwnerTeam Enemy = City->OwnerTeam;
    FEnemyTheory& Theory = EnemyTheories.FindOrAdd(Enemy);
    FCombatBeliefs& Beliefs = Theory.Beliefs;
    
    // Count defenses
    int32 TurretCount = City->GetTurretCount();
    int32 DefenderCount = CountDefendersNearCity(City);
    float CityHP = City->CurrentHealth;
    
    // Calculate vehicles needed based on BELIEFS (not ground truth)
    float VehiclesForTurrets = TurretCount * Beliefs.VehiclesPerTurret;
    float VehiclesForDefenders = DefenderCount * Beliefs.VehiclesPerDefender;
    float VehiclesForCity = CityHP / 150.0f;  // Base estimate: 150 damage per vehicle
    
    float BaseVehiclesNeeded = VehiclesForTurrets + VehiclesForDefenders + VehiclesForCity;
    
    // Apply safety multiplier
    Assessment.VehiclesNeeded = FMath::CeilToInt(BaseVehiclesNeeded * Beliefs.SafetyMultiplier);
    Assessment.VehiclesNeeded = FMath::Max(3, Assessment.VehiclesNeeded);
    
    // Store observed state for learning
    Assessment.TurretsObserved = TurretCount;
    Assessment.DefendersObserved = DefenderCount;
    Assessment.EffectiveStrength = CityHP + (TurretCount * 200.0f) + (DefenderCount * 100.0f);
    
    // Confidence ratio
    Assessment.ConfidenceRatio = (float)Pressures.VehiclesOwned / (float)Assessment.VehiclesNeeded;
    
    // Strategic value
    float WeaknessFactor = FMath::Clamp(1.0f - (Assessment.EffectiveStrength / 3000.0f), 0.2f, 1.0f);
    int32 NearbyResources = CountResourcesNearCity(City);
    float ResourceFactor = 0.5f + FMath::Min(0.5f, NearbyResources * 0.1f);
    Assessment.StrategicValue = WeaknessFactor * ResourceFactor;
    
    // Check for changes since last assessment
    if (Theory.LastKnownStrength > 0.0f)
    {
        float StrengthChange = Assessment.EffectiveStrength / Theory.LastKnownStrength;
        if (StrengthChange > 1.3f)
        {
            // Enemy got significantly stronger - they're rebuilding fast
            Beliefs.EnemyRebuildRate = FMath::Lerp(Beliefs.EnemyRebuildRate, 1.0f, 0.3f);
        }
    }
    
    Theory.LastKnownStrength = Assessment.EffectiveStrength;
    Theory.LastAssessmentTime = CurrentWorldTime;
    
    return Assessment;
}
```

## Multiple Attack Strategies

Instead of one "optimal" approach, the AI can choose different strategies based on personality and situation:

```cpp

enum class EAttackStrategy : uint8

    Calculated,       // Send exactly what beliefs suggest

EAttackStrategy AAITeamController::ChooseAttackStrategy(const FCityAssessment& Target)
{

    FCombatBeliefs& Beliefs = Theory.Beliefs;

    if (Personality.Aggression > 0.7f && Personality.Patience < 0.4f)

        {
            return EAttackStrategy::Aggressive;
        }
    }
    
    // Very cautious = Overwhelming force only
    if (Personality.Caution > 0.7f)
    {
        if (Confidence >= 1.8f)
        {
            return EAttackStrategy::Overwhelming;
        }
        // Otherwise don't attack
        return EAttackStrategy::ChipDamage;  // Maybe harass
    }
    
    // High belief in chip damage value = use attrition

    }

        {

        }
    }
    
    // Default based on confidence
    if (Confidence >= 1.5f)
    {
        return EAttackStrategy::Overwhelming;

    else if (Confidence >= 1.0f)
    {
        return EAttackStrategy::Calculated;
    }
    else if (Confidence >= 0.7f && Personality.Aggression > 0.5f)
    {

    }
    else if (Confidence >= 0.4f && Beliefs.ChipDamageValue > 0.3f)

    }
```

## Strategy-Specific Execution

```cpp
void AAITeamController::ExecuteCityAttack(TArray<AVehicleActor*>& AvailableVehicles, int32 MaxVehicles)
{
    if (!CachedBestTarget.City) return;
    
    EAttackStrategy Strategy = ChooseAttackStrategy(CachedBestTarget);
    FEnemyTheory& Theory = EnemyTheories.FindOrAdd(CachedBestTarget.City->OwnerTeam);
    
    int32 VehiclesToSend = 0;
    EAIAction VehicleObjective = EAIAction::CaptureCities;  // Default: attack city
    
    switch (Strategy)
    {
    case EAttackStrategy::Overwhelming:
        {
            // Send 50% more than needed
            VehiclesToSend = FMath::CeilToInt(CachedBestTarget.VehiclesNeeded * 1.5f);
            VehiclesToSend = FMath::Min(VehiclesToSend, MaxVehicles);
            
            // Only execute if we can actually overwhelm
            if (VehiclesToSend < CachedBestTarget.VehiclesNeeded * 1.3f)
            {
                UE_LOG(LogTemp, Log, TEXT("AI Team %d: Overwhelming attack postponed - need more force"),
                    (int32)ControlledTeam);
                return;
            }
        }
        break;
        
    case EAttackStrategy::Calculated:
        {
            // Send exactly what we think we need
            VehiclesToSend = CachedBestTarget.VehiclesNeeded;
            VehiclesToSend = FMath::Min(VehiclesToSend, MaxVehicles);
            
            if (VehiclesToSend < CachedBestTarget.VehiclesNeeded)
            {
                return;  // Wait until we have enough
            }
        }
        break;
        
    case EAttackStrategy::Aggressive:
        {
            // Send what we have even if it's not quite enough
            float MinConfidence = 0.7f - (Personality.Aggression * 0.2f);  // 0.5 to 0.7
            
            if (CachedBestTarget.ConfidenceRatio < MinConfidence)
            {
                return;
            }
            
            VehiclesToSend = FMath::Min(MaxVehicles, Pressures.VehiclesOwned);
            VehiclesToSend = FMath::Max(3, VehiclesToSend);
        }
        break;
        
    case EAttackStrategy::ChipDamage:
        {
            // Send small force to harass, not expecting to win
            // Goal: deal damage, maybe kill a turret or factory
            VehiclesToSend = FMath::Clamp(MaxVehicles, 2, 4);
            
            // Not worth it if we'd lose them all for nothing
            if (CachedBestTarget.EffectiveStrength > 2000.0f && VehiclesToSend < 3)
            {
                return;
            }
        }
        break;
        
    case EAttackStrategy::Surgical:
        {
            // Target factories specifically
            VehicleObjective = EAIAction::AttackVehicles;  // Repurpose - vehicles will target buildings
            
            // Send enough to maybe kill one factory
            // Factory has 300 HP, vehicle does ~6.67 DPS, so ~45 seconds to kill
            // Need to survive turret fire during that time
            int32 TurretCount = CachedBestTarget.TurretsObserved;
            VehiclesToSend = FMath::Max(3, TurretCount + 2);  // Enough to tank turrets
            VehiclesToSend = FMath::Min(VehiclesToSend, MaxVehicles);
        }
        break;
        
    case EAttackStrategy::Attrition:
        {
            // Trade efficiently - send enough to definitely kill SOMETHING
            // Then retreat (if that's possible in your game)
            VehiclesToSend = FMath::Clamp(MaxVehicles, 3, 6);
        }
        break;
    }
    
    if (VehiclesToSend <= 0) return;
    
    // Record attack start for learning
    FAttackRecord Record;
    Record.Timestamp = CurrentWorldTime;
    Record.TargetCity = CachedBestTarget.City;
    Record.VehiclesSent = VehiclesToSend;
    Record.TurretsObserved = CachedBestTarget.TurretsObserved;
    Record.DefendersObserved = CachedBestTarget.DefendersObserved;
    Record.CityHealthAtStart = CachedBestTarget.City->CurrentHealth;
    
    // Store for completion callback
    PendingAttacks.Add(CachedBestTarget.City, Record);
    
    // Assign vehicles
    int32 Assigned = 0;
    for (AVehicleActor* Vehicle : AvailableVehicles)
    {
        if (Assigned >= VehiclesToSend) break;
        
        if (!AssignedVehicles.Contains(Vehicle))
        {
            Vehicle->AssignedAction = VehicleObjective;
            Vehicle->bHasAssignment = true;
            Vehicle->CurrentTarget = CachedBestTarget.City;
            Vehicle->AIController = this;
            Vehicle->AttackStrategy = Strategy;  // Vehicle knows the strategy
            
            AssignedVehicles.Add(Vehicle);
            Assigned++;
        }
    }
    
    UE_LOG(LogTemp, Warning, TEXT("AI Team %d: %s attack on %s with %d vehicles (need %d, confidence %.1fx)"),
        (int32)ControlledTeam, *StrategyToString(Strategy), *CachedBestTarget.City->GetName(),
        Assigned, CachedBestTarget.VehiclesNeeded, CachedBestTarget.ConfidenceRatio);
}
```

```cpp
void AAITeamController::UpdateEnemyIntelligence()
{
    for (auto& TheoryPair : EnemyTheories)
    {
        FEnemyTheory& Theory = TheoryPair.Value;
        
        // Get current enemy cities
        TArray<ACityActor*> EnemyCities = GetTeamCities(Theory.Enemy);
        
        for (ACityActor* City : EnemyCities)
        {
            FCityAssessment Current = AssessEnemyCity(City);
            
            // Check if we have historical data for this city
            for (const FAttackRecord& Record : Theory.AttackHistory)
            {
                if (Record.TargetCity == City)
                {
                    // Compare current strength to when we attacked
                    float TimeSinceAttack = CurrentWorldTime - Record.Timestamp;
                    float StrengthThen = Record.TurretsObserved * 200.0f + 
                                         Record.DefendersObserved * 100.0f + 
                                         Record.CityHealthAtStart;
                    float StrengthNow = Current.EffectiveStrength;
                    
                    if (StrengthNow > StrengthThen * 1.5f && TimeSinceAttack < 120.0f)
                    {
                        // Significant buildup in short time
                        // They're prioritizing defense of this city
                        
                        UE_LOG(LogTemp, Warning, TEXT("AI Team %d: Enemy %d reinforced %s (%.0f -> %.0f in %.0fs)"),
                            (int32)ControlledTeam, (int32)Theory.Enemy, *City->GetName(),
                            StrengthThen, StrengthNow, TimeSinceAttack);
                        
                        // Update rebuild rate estimate
                        float ReinforcementRate = (StrengthNow - StrengthThen) / TimeSinceAttack;
                        Theory.Beliefs.EnemyRebuildRate = FMath::Lerp(
                            Theory.Beliefs.EnemyRebuildRate, 
                            ReinforcementRate / 100.0f,  // Normalize
                            0.3f);
                        
                        // If they rebuild fast, chip damage is less valuable
                        if (Theory.Beliefs.EnemyRebuildRate > 0.8f)
                        {
                            Theory.Beliefs.ChipDamageValue *= 0.8f;
                        }
                    }
                }
            }
        }
    }
}
```

```cpp
            Alternatives.Add(EAttackStrategy::Surgical);

            Alternatives.Add(EAttackStrategy::Aggressive);
            Alternatives.Add(EAttackStrategy::Attrition);

        {
            Alternatives.Add(EAttackStrategy::Calculated);
        }
        if (Target.ConfidenceRatio >= 1.5f)
        {
            Alternatives.Add(EAttackStrategy::Overwhelming);
        }
        
        // Remove the preferred strategy from alternatives
        Alternatives.Remove(PreferredStrategy);

        {

        }
```

## The Axiom Implementation

The axioms don't need to be explicit code structures. They can be implicit in your derivation functions:

```cpp
float DeriveContribution(EAIAction Action, EStrategicGoal Goal)
{
    // Get what this goal requires
    TArray<ERequirement> Requirements = GetGoalRequirements(Goal);
    
    // Get what this action provides
    TArray<ECapability> Capabilities = GetActionCapabilities(Action);
    
    float Contribution = 0.0f;
    
    for (ERequirement Req : Requirements)
    {
        bool bSatisfied = false;
        float SatisfactionAmount = 0.0f;
        
        for (ECapability Cap : Capabilities)
        {
            // This is where axioms live - the matching rules
            if (Req == ERequirement::ReachTarget && Cap == ECapability::Movement)
            {
                bSatisfied = true;
                // Better movement = better satisfaction
                SatisfactionAmount = GetMovementSpeed(Action) / 500.0f; // Normalized
            }
            else if (Req == ERequirement::DealDamage && Cap == ECapability::Attack)
            {
                bSatisfied = true;
                SatisfactionAmount = GetAttackDamage(Action) / 20.0f; // Normalized
            }
            // ... more axiom-based matching
        }
        
        if (!bSatisfied)
        {
            // Critical requirement not met - action can't help this goal
            return 0.0f;
        }
        
        Contribution += SatisfactionAmount;
    }
    
    return Contribution / Requirements.Num(); // Average satisfaction
}
```

The axioms are the `if` statements that define which capabilities satisfy which requirements. That's the handcrafted knowledge. Everything else flows from it.

```cpp
            Contribution -= 0.5f;
```

- **Vehicles** are allocated, not consumed. You assign 3 vehicles to capture, they're still your vehicles.
- **Money** is spent. You buy a factory, money is gone.

The question "should I build vehicles or capture resources?" doesn't make sense - you do both simultaneously with different resources.

## What The Architecture Should Be

Two parallel decision processes:

```
VEHICLE ALLOCATION (What should my vehicles do?)
    |
    ├── For each vehicle action (Capture, Defend, Attack, etc.)
    │   └── Score based on: goal weights × derived contribution × feasibility
    |
    └── Distribute vehicles proportionally to scores

SPENDING DECISION (What should I buy?)
    |
    ├── For each build action (Vehicle, Turret, Factory)
    │   └── Score based on: goal weights × derived contribution × affordability
    |
    └── Execute best affordable OR save for best unaffordable
```

These run independently. The AI might simultaneously:
- Send 3 vehicles to capture resources
- Send 2 vehicles to defend
- Save money for a factory

```cpp
void AAITeamController::AllocateVehicles()
{
    int32 VehiclesRemaining = Pressures.VehiclesOwned;
    
    for (EAIAction Action : SortedVehicleActions)
    {
        float Score = ActionScores[Action];
        if (Score <= 0.0f) continue;
        
        FActionConfig& Config = ActionConfigs[Action];
        
        float ScoreRatio = Score / GetTotalPositiveVehicleScore();
        int32 ToAllocate = FMath::RoundToInt(Pressures.VehiclesOwned * ScoreRatio);
        ToAllocate = FMath::Clamp(ToAllocate, Config.MinVehicles, Config.MaxVehicles);
        ToAllocate = FMath::Min(ToAllocate, VehiclesRemaining);
        
        if (ToAllocate >= Config.MinVehicles)
        {
            Config.AllocatedVehicles = ToAllocate;
            Config.bCanExecute = true;
            VehiclesRemaining -= ToAllocate;
        }
    }
}

void AAITeamController::AllocateSpending()
{
    // Find best build action (already uses affordability scoring)
    EAIAction BestAction = SortedBuildActions[0];
    float BestScore = ActionScoresWithAffordability[BestAction];
    
    if (BestScore <= 0.0f) return;
    
    FActionConfig& Config = ActionConfigs[BestAction];
    
    if (Money >= Config.Cost)
    {
        // Can afford - execute
        Config.AllocatedMoney = Config.Cost;
        Config.bCanExecute = true;
        bWasSavingLastTick = false;
    }
    else
    {
        // Save for it
        LastSavingForAction = BestAction;
        bWasSavingLastTick = true;
    }
}

float AAITeamController::GetTotalPositiveVehicleScore()
{
    float Total = 0.0f;
    for (EAIAction Action : SortedVehicleActions)
    {
        if (ActionScores[Action] > 0.0f)
        {
            Total += ActionScores[Action];
        }
    }
    return FMath::Max(Total, 0.01f);
}
```

## Simple Clustering Algorithm

```cpp
TArray<FResourceCluster> AAITeamController::ClusterResources(TArray<AResourceActor*>& Resources)
{
    TArray<FResourceCluster> Clusters;
    TSet<AResourceActor*> Assigned;
    
    float ClusterRadius = 2500.0f;  // Resources within this distance = same cluster
    
    for (AResourceActor* Resource : Resources)
    {
        if (Assigned.Contains(Resource)) continue;
        
        FResourceCluster Cluster;
        Cluster.Resources.Add(Resource);
        Assigned.Add(Resource);
        
        FVector Sum = Resource->GetActorLocation();
        
        // Find all resources close to this one
        for (AResourceActor* Other : Resources)
        {
            if (Assigned.Contains(Other)) continue;
            
            float Distance = FVector::Dist(Resource->GetActorLocation(), Other->GetActorLocation());
            if (Distance < ClusterRadius)
            {
                Cluster.Resources.Add(Other);
                Assigned.Add(Other);
                Sum += Other->GetActorLocation();
            }
        }
        
        Cluster.Center = Sum / Cluster.Resources.Num();
        Cluster.Radius = ClusterRadius;
        
        Clusters.Add(Cluster);
    }
    
    return Clusters;
}
```

```cpp
void AAITeamController::AssessTargetThreats(FStrategicTarget& Target)
{
    Target.TotalThreat = 0;
    
    // Find enemy turrets covering this area
    for (ATurretBuildingActor* Turret : GetAllEnemyTurrets())
    {
        float Distance = FVector::Dist(Turret->GetActorLocation(), Target.Center);
        if (Distance < Turret->AttackRange + Target.Radius)
        {
            Target.EnemyTurrets.Add(Turret);
            Target.TotalThreat += 2;  // Turrets are worth 2 vehicles
        }
    }
    
    // Find enemy vehicles near this area
    for (AVehicleActor* Vehicle : GetAllEnemyVehicles())
    {
        float Distance = FVector::Dist(Vehicle->GetActorLocation(), Target.Center);
        if (Distance < Target.Radius + 1500.0f)  // Detection range
        {
            Target.EnemyVehicles.Add(Vehicle);
            Target.TotalThreat += 1;
        }
    }
    
    // Find my vehicles near this area
    for (AVehicleActor* Vehicle : GetTeamVehicles())
    {
        float Distance = FVector::Dist(Vehicle->GetActorLocation(), Target.Center);
        if (Distance < Target.Radius + 2000.0f)
        {
            Target.MyVehiclesNearby++;
        }
    }
    
    // Confidence ratio
    int32 MyForce = Target.MyVehiclesNearby;
    int32 TheirForce = Target.TotalThreat;
    Target.ConfidenceRatio = (TheirForce > 0) ? (float)MyForce / TheirForce : 10.0f;
}
```

## Intent Scoring

```cpp
void AAITeamController::ScoreTargetIntents(FTargetEvaluation& Eval)
{
    FStrategicTarget* T = Eval.Target;
    
    float PrizeValue = T->Resources.Num() * 1.0f + T->Cities.Num() * 5.0f;
    float Distance = GetDistanceFromNearestCity(T->Center);
    float DistancePenalty = Distance / 5000.0f;  // Far = less attractive
    
    // CAPTURE: Take and hold
    // Requires high confidence, rewards based on prize value
    if (T->ConfidenceRatio >= 1.2f)
    {
        Eval.CaptureScore = PrizeValue * T->ConfidenceRatio - DistancePenalty;
        Eval.CaptureScore *= (0.5f + DesireWeights.Dominance * 0.5f);
    }
    
    // CONTEST: Fight for it, might not win
    // Requires moderate confidence, aggressive personality helps
    if (T->ConfidenceRatio >= 0.5f && T->ConfidenceRatio < 1.5f)
    {
        Eval.ContestScore = PrizeValue * 0.7f - DistancePenalty;
        Eval.ContestScore *= Personality.Aggression;
        Eval.ContestScore *= (1.0f - Personality.Caution * 0.5f);
    }
    
    // HARASS: Hit and run, don't commit
    // Any confidence, good for chip damage
    if (T->Cities.Num() > 0)  // Only harass cities, not resource clusters
    {
        Eval.HarassScore = T->Cities.Num() * 2.0f - DistancePenalty * 0.5f;
        Eval.HarassScore *= (0.3f + DesireWeights.Dominance * 0.4f);
        // Even cautious AIs can harass
    }
    
    // CONTAIN: Surround, deny, wait
    // Good when can't capture but want to prevent enemy growth
    if (T->ConfidenceRatio >= 0.7f && T->ConfidenceRatio < 1.3f)
    {
        Eval.ContainScore = PrizeValue * 0.5f;
        Eval.ContainScore *= DesireWeights.Security;
        Eval.ContainScore *= Personality.Patience;
    }
    
    // Find best intent
    Eval.BestScore = Eval.CaptureScore;
    Eval.BestIntent = ETargetIntent::Capture;
    
    if (Eval.ContestScore > Eval.BestScore)
    {
        Eval.BestScore = Eval.ContestScore;
        Eval.BestIntent = ETargetIntent::Contest;
    }
    // ... etc for other intents
}
```

```
  │       │       └─ CHECK: Can I capture resources? YES
  │       │           └─ ACTION: Send vehicles to capture resources

  │           └─ ACTION: Build vehicles
  └─ CHECK: Do I have enough vehicles now? YES
```

## The Key Insight: Goals Have Prerequisites

Every goal has **preconditions** that must be satisfied before it can be pursued:

```cpp
struct FGoalPreconditions
{
    // Resource requirements
    int32 MinVehicles = 0;
    int32 MinMoney = 0;
    float MinIncomePerMinute = 0.0f;
    
    // Situational requirements
    float MinConfidenceRatio = 0.0f;  // For attack goals
    bool bNeedsSafeTerritory = false; // For economic goals
    
    // What goal to pursue if preconditions fail
```

## Implementation: Recursive Goal Resolution

```cpp
struct FGoalResolution
{
    EStrategicGoal OriginalGoal;      // What I wanted
    EStrategicGoal ActiveGoal;         // What I'm actually doing
    TArray<EStrategicGoal> GoalChain;  // How I got here
    bool bIsPrerequisite = false;      // Am I working toward something bigger?
    float TimeHorizon = 0.0f;          // How long until original goal is achievable
};

FGoalResolution AAITeamController::ResolveGoal(EStrategicGoal Goal, int32 Depth = 0)
{
    FGoalResolution Resolution;
    Resolution.OriginalGoal = Goal;
    Resolution.GoalChain.Add(Goal);
    
    // Prevent infinite recursion
    if (Depth > 5)
    {
        Resolution.ActiveGoal = EStrategicGoal::Survive;
        return Resolution;
    }
    
    // Check preconditions
    FGoalPreconditions Preconditions = GetGoalPreconditions(Goal);
    
    // === VEHICLE CHECK ===
    if (Preconditions.MinVehicles > 0 && Pressures.VehiclesOwned < Preconditions.MinVehicles)
    {
        int32 VehiclesNeeded = Preconditions.MinVehicles - Pressures.VehiclesOwned;
        int32 CostToBuild = VehiclesNeeded * 1000;  // $1000 per vehicle
        
        // Can we afford to build them?
        float TimeToAfford = (CostToBuild - Money) / (Pressures.IncomePerMinute / 60.0f);
        
        if (TimeToAfford > 120.0f)  // More than 2 minutes away
        {
            // Income too low - need to boost income first
            FGoalResolution SubResolution = ResolveGoal(EStrategicGoal::BuildIncome, Depth + 1);
            SubResolution.GoalChain.Insert(Goal, 0);  // Prepend original goal
            SubResolution.bIsPrerequisite = true;
            SubResolution.OriginalGoal = Goal;
            return SubResolution;
        }
        else if (TimeToAfford > 0.0f)
        {
            // Can afford soon - work on military buildup
            Resolution.ActiveGoal = EStrategicGoal::Prepare;
            Resolution.TimeHorizon = TimeToAfford;
            return Resolution;
        }
        // Else: can afford now, fall through
    }
    
    // === MONEY CHECK ===
    if (Preconditions.MinMoney > 0 && Money < Preconditions.MinMoney)
    {
        float TimeToAfford = (Preconditions.MinMoney - Money) / (Pressures.IncomePerMinute / 60.0f);
        
        if (TimeToAfford > 60.0f)  // More than 1 minute
        {
            // Need more income
            FGoalResolution SubResolution = ResolveGoal(EStrategicGoal::ExpandIncome, Depth + 1);
            SubResolution.GoalChain.Insert(Goal, 0);
            SubResolution.bIsPrerequisite = true;
            SubResolution.OriginalGoal = Goal;
            return SubResolution;
        }
        // Else: just wait
    }
    
    // === CONFIDENCE CHECK (for attack goals) ===
    if (Preconditions.MinConfidenceRatio > 0.0f)
    {
        if (!CachedBestTarget.City || CachedBestTarget.ConfidenceRatio < Preconditions.MinConfidenceRatio)
        {
            // Not strong enough - build up
            Resolution.ActiveGoal = EStrategicGoal::Prepare;
            return Resolution;
        }
    }
    
    // All preconditions met - pursue the goal directly
    Resolution.ActiveGoal = Goal;
    return Resolution;
}
```

```cpp
        Preconditions.MinVehicles = 1;
        break;

        Preconditions.MinMoney = 3000;
        break;

        // Always possible (turrets, garrison)
        break;
        
    case EStrategicGoal::Prepare:
        // Need income to build up
        Preconditions.MinIncomePerMinute = 1200.0f;  // At least 1 income source
```

## The New Decision Flow

```cpp
void AAITeamController::CalculateGoalWeights()
{
    // Step 1: Calculate RAW goal weights from desires (what do I WANT?)
    TMap<EStrategicGoal, float> RawGoalWeights;
    CalculateRawGoalWeights(RawGoalWeights);  // Current logic
    
    // Step 2: Resolve each goal through prerequisite chain
    TMap<EStrategicGoal, FGoalResolution> Resolutions;
    
    for (auto& Pair : RawGoalWeights)
    {
        if (Pair.Value > 0.1f)  // Only resolve significant goals
        {
            FGoalResolution Resolution = ResolveGoal(Pair.Key);
            Resolutions.Add(Pair.Key, Resolution);
        }
    }
    
    // Step 3: Build final goal weights based on what's actually achievable
    GoalWeights.Empty();
    
    for (auto& Pair : Resolutions)
    {
        EStrategicGoal OriginalGoal = Pair.Key;
        FGoalResolution& Resolution = Pair.Value;
        float OriginalWeight = RawGoalWeights[OriginalGoal];
        
        // The ACTIVE goal gets the weight, not the original
        float& ActiveWeight = GoalWeights.FindOrAdd(Resolution.ActiveGoal);
        ActiveWeight += OriginalWeight;
        
        // Track the chain for debugging
        if (Resolution.bIsPrerequisite)
        {
            UE_LOG(LogTemp, Warning, TEXT("Goal Chain: %s → %s (prerequisite)"),
                *GoalToString(OriginalGoal), *GoalToString(Resolution.ActiveGoal));
        }
    }
    
    // Normalize
    NormalizeGoalWeights();
}
```

## The Power: Emergent Long-Term Planning

With this system, an aggressive AI that can't attack will automatically:

1. Realize it needs more vehicles (Conquer → Prepare)
2. Realize it can't afford vehicles fast enough (Prepare → BuildIncome)
3. Realize it can't afford factories (BuildIncome → ExpandIncome)
4. Capture resources to boost income
5. Now can afford factories faster
6. Build factories
7. Now can afford vehicles faster
8. Build vehicles
9. Now can attack

**The AI "plans ahead" without explicit planning** - it's just recursively resolving prerequisites.
